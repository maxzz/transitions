**User**

Since this application now uses React 19.3—which supports the <ViewTransition />—you need to use this new API to implement a transition animation when navigating from the Hero page to the main application page upon clicking the "Enter the Laboratory" button; similarly, a transition should also be implemented when navigating back to the Hero page from the main page.
View Transitions became stable in React version 19.3, so you can use them. However, if the documentation is insufficient, check this URL: https://react.dev/reference/react/ViewTransition.

Hero ↔ laboratory navigation now uses React 19.3 `<ViewTransition />`.

**Enter the laboratory** slides the lab in from the right (hero exits left). Clicking the header hummingbird reverses that. The logo is a **shared element**, so it morphs from the large hero mark into the small header icon and back.

View Transitions only run for updates inside `startTransition` (or Suspense / `useDeferredValue`). Valtio’s `useSnapshot` is an external store, so it would skip the animation. Page switches now go through React state in the same `startTransition` as `addTransitionType("nav-forward" | "nav-back")`, while `openPage` still persists the last page.

`prefers-reduced-motion: reduce` collapses the CSS animations. Returning to the hero also skips Motion’s first-load fade so it doesn’t fight the view transition.

Verified in the browser: both directions called `document.startViewTransition` with no errors, and the visualizer still ran after entering the lab.
