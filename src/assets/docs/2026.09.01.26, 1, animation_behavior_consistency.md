**User**

When the tradition ends for the React Spring and Motion libraries, the animation ends at the Target position. 
While for animation, the animation for the GSAP ends at the Target position and then resets to the starting position almost immediately.

For each of three libraries, this behavior must be the same. 
To do this, you must first implement a checkbox that will say whether to return the image in a mechanical response 
view to the initial state after the animation ends or leave the animation in the Target position. 
That is, the behavior must be the same for all three libraries.

Even when the "Return to initial position" option is enabled, the return should occur after a one-second delay. 
This allows the user to process what happened during the animation before the system automatically reverts 
to the starting state. Thanks to this delay, pressing the play button again starts the animation 
from a static position rather than causing a jarring jump—where the animation snaps from the end point back 
to the start and immediately restarts, making it nearly impossible to focus on the actual content of the action.
