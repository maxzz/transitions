The first launch now opens a full-viewport **Hero Page**. Preference and last-viewed page are stored in Valtio (same style as the rest of the app’s persisted settings), and the hero lives in its own `hero-page` folder.

**Launch behavior**
- First visit on a machine shows the hero.
- `Don't show this page again` sets `showHeroPage` to `false`, saves it, and goes to the visualizer.
- `Enter the laboratory` goes to the visualizer without opting out.
- `lastViewedPage` is always written, even when the hero still shows next time.

Both values persist under `tm-hero-page__v1`. After opt-out, reload skips the hero and opens the last viewed page.

**Motion sequence**
1. The page fades in.
2. After a short delay, the hummingbird logo springs in.
3. The description types out like generated copy (Motion `animate` + a motion value, not React state).

`MotionConfig reducedMotion="user"` keeps opacity on and drops the logo scale when the user prefers reduced motion; the description then appears in full.

**Where it lives**
- New code: `src/components/2-main/hero-page/`
- Wiring: `src/components/0-all/0-app.tsx` (page switch only)
- Header and visualizer files are unchanged

To see the hero again on this machine, remove `tm-hero-page__v1` from localStorage.
