That’s excellent—exactly what’s needed—with the caveat that dimensions within the view model and view graph must be tied to the container size using container queries.
This ensures that resizing the entire window results in a smooth transition rather than abrupt jumps at various breakpoints. 
Furthermore, since these views might be located in different places, they shouldn't depend on the window's width or height; instead, they should rely on the dimensions provided by the container.
	
The only exception where we rely on breakpoints is when the window becomes very narrow: 
the control panel appears at the top, and two views are displayed beneath it—one for the model and 
one for the graph—depending on whether the mode calls for showing both images or just one of them.	

Leverage the power of Tailwind CSS as much as possible.
