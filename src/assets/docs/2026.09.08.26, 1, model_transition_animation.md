When the option to return to the initial position is enabled, the transition from the model's last state to the new state (specifically, returning to the model's initial state) must be achieved by smoothly reducing the opacity value to zero, followed by resetting it to one at the new position. 
This is necessary to minimize the visual "jerkiness" of the model preview on the screen. 
Use the Motion library to implement this; the animation must be implemented for all five modes: spring, scaling, vertical movement, rotation, and opacity.
This animation should apply only to the elements that move during the model demonstration—for example, in the case of a spring, it would be the spring itself and the weight suspended from it; for vertical movement, it would be just the rectangle that moves, and so on.
