That `<rect>` is an invisible click target for the whole preview.

The SVG listens for `onClick={togglePauseResume}` and shows `cursor-pointer`, but empty SVG space usually does not receive pointer events. Only painted shapes (the coil, mass, lines, text) would be clickable.

The rect matches the `700×650` viewBox and uses `fill-transparent`, so it fills the canvas without drawing anything. Clicks in the gaps still hit this rect and bubble to the SVG, which pauses or resumes playback. The mass still has its own click handler (`stopPropagation` + play/stop), so those clicks do not go through this backdrop.
