The leftover **1.01** was react-spring’s rest threshold, not a display bug. The integrator stopped as soon as it was within `precision` (default `0.01`) of the target, and that leftover became the settled pose. That’s why you saw **101%**, **91°**, and **1.01** when “return to initial position” was off.

Real react-spring snaps to the exact target when the spring goes idle. The replica now does the same, so the last sample is **1.0**.

With return-to-initial disabled, those previews now finish at:

- movement → **1.00**
- scale → **1.00**
- rotation → **90°**
- opacity → **100%**

Overshoot during the run is unchanged; only the settled value is snapped.
